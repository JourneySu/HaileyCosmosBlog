>事情明明做完了，身體卻還是放鬆不下來？
>那可能不是你抗壓性差，而是身體的「煞車」失靈了。**

《神經可塑性》用神經系統解釋了這件事：
壓力是**正常的**，是人體裡的保護機制，
真正有問題的是它一直「關不掉」，
好消息是，壞掉的煞車是可以修復的。

## 一、壓力是怎麼形成的？
我們常聽到的「自律神經系統」，
裡面包含了**交感神經**與**副交感神經**，
在正常的運作下，會維持平衡狀態．　

它們分別的功用是：

|      | 交感神經         | 副交感神經            |
| ---- | ------------ | ---------------- |
| 用途   | 戰鬥或逃跑        | 休息與消化            |
| 身體反應 | 心跳加快、精神集中    | 心跳變慢、放鬆修復        |
| 誰負責  | 杏仁核（警報器）發出訊號 | 迷走神經送出「可以放鬆了」的訊號 |
| 比喻   | **油門**       | **煞車**           |

它們彼此合作的過程很簡單：
1. 當壓力出現，杏仁核拉警報
2. **交感神經**踩油門，活化身體反應，能夠提高意識、增加能量和集中注意力
3. 當壓力解除，**副交感神經**踩煞車，身體**回到平衡**

但若是壓力一直都沒解決的話呢？

## 二、壓力是如何變成慢性壓力的？
當碰上長期未解除的壓力，
例如常態加班、長期處在有壓力關係下，
油門就一直踩著，煞車沒機會接手。

時間一久，杏仁核會變大、變敏感，一點小事就響警報，
人越來越容易焦慮、煩躁，也越來越難放鬆。
就會從正常的壓力，轉變成**慢性壓力**。

## 三、改善慢性壓力的5個習慣
書中提到五個幫身體找回煞車的工具：
1. **好好睡覺**：每天睡眠時間至少6~8小時。
2. **冥想/靜坐**：放空頭腦，讓過度敏感的杏仁核縮小，每天五分鐘也好。
3. **定期運動**：釋放「腦源性神經營養因子」，也就是大腦的養分。
4. **去除多餘的東西**：設立界線，學會說「不」，移開消耗能量的人事物。首先要先去察覺是什麼在消耗自己。
5. **培養嗜好**：規律從事投入的嗜好，同樣能釋放大腦養分，有潛在抗憂鬱作用。

這五件事都不新鮮，
但當知道它們是在**修煞車**之後，
就會知道這是必須做的事，而不是等到有空才做。

不過，說來簡單，做來難呀，
